## Help shape the federation

This profile, and the SOLL scenario in particular, is written in the open. Everyone in the community is invited to help.

- **Give feedback** with the feedback button at the bottom right of this page. It opens a GitHub issue or an e-mail to durf@surf.nl.
- **Edit a section**: every section has an *Edit this section* link to its Markdown file on GitHub.
- **Change the assessment**: open the IST or SOLL assessment in the SPII tool with the link next to the honeycomb, change the answers and notes, save the file and propose it as a change to `data/assessments/` in the [repository](https://github.com/durf-project/gorc-profile).
- **Talk to the theme leads** of theme 1, Simone Kortekaas (KB) and Maurice Vanderfeesten (SURF), or come to the next DURF Federation Day.
